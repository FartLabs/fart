# Type Example

A walkthrough of what Fart source becomes. Every snippet on this page was run
against the transpiler in this repository, so the input and output match.

> ⚠️ **Historical note:** this page used to document a Pokémon example that
> lived in `ex/`. That directory was removed in the #34 rework, and the
> `array %`, `dict %`, and `fn %` modifiers it used no longer parse. The example
> below shows the syntax the transpiler accepts today.

## Type definitions

A `type` block declares a struct. Properties are `name: type`, and a `?` marks
one optional:

```fart
type User {
  id: string
  name: string
  age?: number
}
```

becomes:

```ts
// Auto-generated by Fart Transpiler

export interface User {
  id: string;
  name: string;
  age?: number;
}
```

## The type vocabulary

The transpiler currently accepts these property types:

| Fart                          | TypeScript                                        |
| ----------------------------- | ------------------------------------------------- |
| `string`, `number`, `boolean` | the same                                          |
| `SomeType`                    | `SomeType` — a reference to another declared type |
| `'literal'`                   | `literal` — note the quotes are dropped           |
| `(string)`                    | `[string]` — a single-element tuple               |
| `()`                          | `[]` — an empty tuple                             |
| `name?: T`                    | `name?: T` — optional                             |

## Referencing other types

Types can reference each other, and forward references are fine:

```fart
type Pokemon {
  name: string
  num: number
  ball?: Pokeball
}

type Pokeball {
  id: string
  odds: number
}
```

```ts
// Auto-generated by Fart Transpiler

export interface Pokemon {
  name: string;
  num: number;
  ball?: Pokeball;
}

export interface Pokeball {
  id: string;
  odds: number;
}
```

## What does not work yet

The cartridge defines `array % T`, `dict % <K, V>`, and `fn % <In, Out>`
modifiers, but the tokenizer rejects them today:

```fart
type Bag {
  balls: array % Pokeball
}
```

```
Expected token kind 0 or 3, but got %
```

The same applies to the `ReservedType` helpers (`Omit`, `Default`) and to the
older `name*: T` optionality syntax the previous example used. Treat those as
work in progress rather than documented behavior.

## Running the transpiler

```ts
import { transpile } from "./lib/transpile/mod.ts";
import { generateTypeScriptCartridge } from "./lib/transpile/cartridge/ts_cartridge.ts";

const output = await transpile(
  `type User {
  id: string
  name: string
  age?: number
}`,
  { codeCartridge: generateTypeScriptCartridge() },
);
```

A different cartridge produces a different target language, which is how the
same source compiles to more than one language.

## Compiling over HTTP

The Fart Server exposes the same transpiler at `/ts/`, for Fart source hosted in
any public GitHub repository:

```
/ts/{owner}/{repo}/{branch}/path/to/source.fart
```

Responses are served with permissive CORS, so Deno can import them directly:

```ts
import type { User } from "https://fart.fart.tools/ts/{owner}/{repo}/{branch}/user.fart";
```

Note that no `.fart` files are committed to this repository, so you will need a
repository that actually contains Fart source to try this.

## Syntax highlighting

To view a file with GitHub-style HTML highlighting instead of generated code,
use the `/html.syntax.gh/` prefix. This works for any text file, not just Fart
source.
